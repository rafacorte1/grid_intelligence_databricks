# Grid Intelligence

A governed Databricks lakehouse and operations copilot for a fictional electric utility.

The project connects synthetic power interruptions, electricity consumption and
service calls through Bronze, Silver and Gold SQL pipelines, a shared continuity
metric view, an AI/BI dashboard and a Portuguese Genie copilot.
